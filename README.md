# Hosting Qwen 2.5 7B on Google Colab with vLLM

Host and serve the **Qwen2.5-7B-Instruct-GPTQ-Int4** Large Language Model on a free Google Colab Tesla T4 GPU using **vLLM** and **ngrok**, and interact with it from your local machine via a terminal chat client (`chathost.py`).

---

## 📌 Project Overview

- **Model:** `Qwen/Qwen2.5-7B-Instruct-GPTQ-Int4` (4-bit quantized, taking ~5.2 GB VRAM)
- **Inference Engine:** [vLLM](https://github.com/vllm-project/vllm) for fast OpenAI-compatible serving
- **Tunneling:** [ngrok / pyngrok](https://ngrok.com/) to expose the local Colab server to the internet
- **Client:** `chathost.py` - terminal chat client with `.env` configuration support
- **Example Output:** `tiktactoe.html` - a playable web Tic-Tac-Toe game generated directly by the model

## 🚀 Setup & Execution Guide

### Step 1: Host the Model on Google Colab

No local installation is needed for the host—simply run the notebook on Google Colab:

1. **Open the Notebook in Colab:**
   - Upload and open `Qwen2_5_7B_Host.ipynb` in [Google Colab](https://colab.research.google.com/).
   - Ensure the runtime is set to GPU: **Runtime** > **Change runtime type** > **T4 GPU**.

2. **Run the Notebook Cells:**
   - Execute the installation cells to install `vllm` and `pyngrok`.
   - Launch the vLLM server:
     ```bash
     vllm serve Qwen/Qwen2.5-7B-Instruct-GPTQ-Int4 \
         --quantization gptq \
         --gpu-memory-utilization 0.70 \
         --max-model-len 4096 \
         --enforce-eager \
         --host 0.0.0.0 \
         --port 8000 \
         --api-key "EMPTY"
     ```
     *(You can set a custom API key by replacing `"EMPTY"` if desired).*

3. **Get your Public Ngrok URL:**
   - Run the ngrok tunnel cell in the notebook:
     ```python
     from pyngrok import ngrok
     public_url = ngrok.connect(8000)
     print("Public Ngrok URL:", public_url)
     ```
   - Copy the generated HTTPS URL (e.g. `https://overprice-decaf-naming.ngrok-free.dev`).

---

### Step 2: Set Up Local Chat Client

Install requirements and configure the local environment to chat with your hosted model:

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd Hosting_Qwen2_5_7B_Google_Colab
   ```

2. **(Optional) Create and activate a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Client Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure `.env`:**
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Open `.env` and paste your ngrok URL:
   ```env
   HOST_BASE_URL="https://your-ngrok-subdomain.ngrok-free.dev/v1"
   HOST_MODEL="Qwen/Qwen2.5-7B-Instruct-GPTQ-Int4"
   HOST_API_KEY="EMPTY"
   ```

5. **Start Chatting:**
   ```bash
   python3 chathost.py
   ```
